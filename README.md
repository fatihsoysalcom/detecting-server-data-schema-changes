# Detecting Server Data Schema Changes

This example simulates a monitoring agent interacting with a server whose data reporting structure changes after an update. It demonstrates how an agent expecting a specific data schema can fail to interpret or process information correctly when the server's output format evolves, highlighting the challenges in dynamic environments like MCP servers.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
